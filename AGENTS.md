# Instructions for all coding agents

Read `CLAUDE.md` first — every rule there applies to you, whichever CLI you are.

Additionally:
- Create and modify files with your editor tools (write/edit), never shell
  heredocs/redirection.
- Path-stage commits (`git add <files>`), never `-A`.
- Numbers require executed, cited measurements — and the 90.6% figure is banned (debunked).
